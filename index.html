        Opsional. Dengan akun cloud, data tersinkron di semua perangkat Anda, setiap orang (misalnya adik Anda) punya akun sendiri, dan posisi MT5 bisa masuk otomatis.

        1. Buat proyek gratis di supabase.com.
        2. Buka SQL Editor, tempel isi file supabase-setup.sql, lalu jalankan.
        3. Salin Project URL dan anon / publishable key dari Project Settings → API ke kolom di bawah.

        Masuk atau daftar

        Masuk sebagai .

        Hubungkan MT5

        1. Salin file RiskDesk_Bridge.mq5 ke folder MQL5/Experts (MT5 → File → Open Data Folder), lalu compile di MetaEditor.
        2. Di MT5: Tools → Options → Expert Advisors → centang Allow WebRequest dan tambahkan Project URL Supabase Anda.
        3. Pasang EA di satu chart mana saja (seret dari Navigator → Expert Advisors), centang Allow Algo Trading, lalu isi tiga nilai di bawah ini.

        Isi tiga nilai ini di tab Inputs EA. SyncToken berbeda untuk setiap akun, jadi data MT5 setiap orang hanya masuk ke akunnya sendiri.
